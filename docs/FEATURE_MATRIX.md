# Feature implementation matrix

States: **Implemented** = real code and referenced checks; **Partial** = a working subset;
**Simulated** = explicitly labelled visual/test data; **Absent** = no backend. A passing build
is not device verification. Platform evidence and outstanding acceptance are in [STATUS](STATUS.md).

| Area | State | Actual behaviour | Evidence / missing part |
| --- | --- | --- | --- |
| Session, tracks, regions, timeline data | Implemented | Rust model, stable IDs, integer PPQ 960, validated edits, musical settings | project/model.rs, edit.rs, validate.rs; Rust tests and generated bindings |
| Save/open/save-as, undo/redo | Implemented | Atomic .elyvon schema-5 files (schema 1–4 migrated on open); snapshot history with a memory budget, dirty tracking, two-phase save; every timeline/audio edit is one undo step | tests/persistence.rs (v1 + v2 fixtures), tests/io.rs; native e2e/app.e2e.mjs |
| Recovery and unsaved guards | Implemented | Recovery snapshots, backend refuses destructive operations without explicit discard | recovery/session tests; native E2E |
| GUI process restart + reload saved file | Implemented automated check | Stops native process, starts another, opens saved project and compares model | Native E2E; file dialogs are bypassed via real native IPC |
| Arrangement | Implemented (Phase 11 scope) | Move, trim, split, duplicate, cut/copy/paste, region mute, gain, fades with three shapes, editable crossfades, loop, reverse, slip (Ctrl+Alt-drag), ripple delete, marquee split/delete/ripple, glue of contiguous pieces, transient slices and markers, normalise (region gain), bounce in place, phase-locked group edits; metre-aware ruler/grid; snap with triplets/swing; markers; engine-driven playhead | timeline_edit.rs, region_edit.rs and elyvon-audio/tests/editing.rs; tempoMap golden vectors; native E2E. No flex time, no sample-level editor |
| Takes and comping | Implemented, microphone recording unverified | Take folders from cycle recordings; comp by dragging across takes; crossfades centred on boundaries; flatten/unflatten (sample-identical); takes kept unchanged | elyvon-audio/tests/comping.rs (real capture writer, export, reopen, undo); native E2E with exported-sample check |
| Automation | Implemented (Phase 10), hardware unverified | Track/region/aux/master lanes for volume, pan, mute, send levels and insert parameters; Off/Read/Touch/Latch/Write; linear/step/Bézier; lane editor; mixer controls capture while playing | elyvon-audio/tests/automation.rs (RMS ramp, filter sweep, block-size and live/offline identity, 100 000 points, tempo maps), project tests, rt_alloc, native E2E fader capture. No control surfaces |
| Freeze and media repair | Implemented | Pre-fader freeze with fingerprint checks and locked material; missing-file search by content; collect media; unused files moved to a backup only with confirmation | editing.rs freeze test, tests/media_repair.rs, native E2E |
| Piano roll | Implemented, hardware/UI-on-device partially verified | Canvas editor (HiDPI, culled drawing) for one or several MIDI regions: pointer/pencil/eraser, rubber-band and multi-select, drag in time and pitch with metre-aware snap (1/1…1/32, triplets, swing), Alt-drag copy, edge resize, nudge/transpose keys, duplicate, delete, mute; velocity lane and CC1/7/11/64, pitch-bend, pressure and program lanes; reversible quantise with strength, unquantise, deterministic humanise, transpose, legato, fixed velocity/channel/length, chord-voice split; scale highlighting; audition through the built-in instrument or MIDI out; every gesture one native undo step (`batch` for multi-region) | midi_edit.rs unit tests, elyvon-project/tests/piano_roll.rs (150 random edits undone/redone 3×, 10 000-note benchmark), elyvon-audio/tests/piano_roll.rs (tempo ramp + irregular metres, block sizes 64/512/1031, SMF equivalence, edits during playback), pianoRollModel.test.ts, native E2E pencil test. No MIDI 2.0 per-note expression (absent), no step input, no automation lanes other than MIDI controllers |
| Mixer | Implemented (Phase 09 scope), hardware unverified | Engine graph: track and aux strips with format (auto/mono/stereo), typed inserts, pre/post-fader sends, fader with ramped gain, three pan laws, mute (silences sends), solo with destination/source path keeping and solo-safe, output to master or aux, master strip with inserts; groups linking volume/pan/mute/solo; folders (mixer only); stems export | elyvon-audio/tests/mixer.rs (bit-exact unity A→bus→master, pan laws, sends, solo/mute, groups, cycle rejection, save/reopen, meters/clip, click-free graph swaps, PDC alignment and phase, inserts, stems sum = master), rt_alloc.rs graph test, native E2E bus routing + meters. Automation in the Automation row; no VCA, surround or third-party plug-ins; folder collapse is mixer-only |
| Waveforms | Implemented | Real min/max columns from a peak pyramid of the decoded file, through tempo map/offset/loop; LRU cache, only the visible part is requested. | Meters | Implemented | Per-strip post-fader peak (lock-free `fetch_max`), ~300 ms RMS from monotonic sums, 1.5 s peak hold (UI, from real peaks), sticky clip with reset, master after output summing; no simulation path remains | transport.rs MeterSlot/MeterReader, mixer.rs meters test, native E2E. No LUFS/true-peak |
| Audio engine and transport | Implemented, hardware unverified | Lock-free RT engine; play/stop/pause/locate, cycle, count-in, pre-roll, metronome, tap tempo; tempo/metre map; cpal device output with internal-clock fallback | timing.rs, playback.rs, rt_alloc.rs, device.rs tests; native E2E plays under Xvfb on the internal clock. **No physical device test** |
| Audio files (import, decode, resample) | Implemented, bounded RAM/disk cache | WAV/AIFF/FLAC/MP3/Ogg Vorbis via Symphonia, any rate resampled (rubato FFT); dialog, OS drag-and-drop, browser; missing/changed files reported; relink | media.rs, session.rs tests; native E2E import. | Offline render / diagnostic export | Implemented | Same engine path, 32-bit float WAV + JSON report (levels per channel/track, checksum); master + post-fader stems per audio/instrument track and aux, plus stems.json | session.rs, timing.rs, mixer.rs stems test (sum equals master, files decode back); native E2E |
| Recording, punch recording, input monitoring | Partial; native implementation, hardware unverified | CPAL input, per-track arming/channels, software monitor, multitrack WAV/BWF worker, count-in/pre-roll/punch/cycle, take groups/selection, checkpoint and recovery journals | recording.rs/input.rs and recording integration/RT tests; no physical voice/guitar/loopback test, concurrent multiple-input-device clock domains or live input SRC |
| MIDI scheduling, ports and recording | Partial; native implementation, hardware unverified | Sample-accurate note/channel/SysEx events handed to a native MIDI worker; filtering, persisted routing, input monitor, virtual keyboard, sequence recording, SMF 0/1 import/type-1 export, panic and explicit missing-port handling | midi.rs tests and native E2E; OS/device sends have measured jitter, not guaranteed sample accuracy. Live input, virtual keyboard and previews play the built-in test instrument on instrument tracks. No UMP, physical-device validation or playback note chase |
| Audio graph and latency compensation | Implemented (insert latency) | Plan-time DAG with topological aux order, per-edge delay lines aligning every summing point to its slowest input; limiter look-ahead is the reported latency; state adopted across swaps | mixer.rs PDC/phase tests; total latency reported (`mixer_status`) but the timeline is not shifted to hide it; no hosted plug-ins |
| AudioProcessor / native DSP | Partial | Trim, utility, 2nd-order HP/LP filter and look-ahead limiter; inserts fade in when added or re-enabled during playback | dsp.rs tests; the old `AudioProcessor` trait remains an unused contract; no plug-in hosting |
